### Docker disadvantages:
* If the containers are on the same VM the bridge network helps for communication between containers .
* When containers runs on different VMS  the network bridge wont work , we need overlay network and it is not possible in docker
* The volume management is not that great,when the VMS crashes the the volume lost 
* Autoscaling is another challange 
* Secret managemnt is not possible 
* Orchestration in docker is possible by Dockerswarm, but it is not recommnded for the production of large enterprise applications.

### K8S Architecture :
* Master node - kubectl , etcd , kube-scheduler 
* Worker node - kubelet 

### EKS Setup :
* Workstation setup
    * Install docker  - To build docker images 
    * Install eksctl  - To manage / create eks cluster
    * Install kubectl - For cluster communication
    * Install Aws cli - To authenticate AWS while creating cluster

* Create a VM in AWS with 50GB volume 

* Install docker on RHEL:
    ```
    sudo dnf remove -y podman buildah runc
    sudo dnf config-manager --add-repo https://download.docker.com/linux/rhel/docker-ce.repo
    sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
    sudo systemctl start docker
    sudo systemctl enable docker
    sudo usermod -aG docker ec2-user

    docker --version
    ```

* Install eksctl :

    ```
    # for ARM systems, set ARCH to: `arm64`, `armv6` or `armv7`
    ARCH=$(uname -m | sed 's/x86_64/amd64/' | sed 's/aarch64/arm64/')
    PLATFORM=$(uname -s)_$ARCH

    curl -sLO "https://github.com/eksctl-io/eksctl/releases/latest/download/eksctl_$PLATFORM.tar.gz"

    # (Optional) Verify checksum
    curl -sL "https://github.com/eksctl-io/eksctl/releases/latest/download/eksctl_checksums.txt" | grep $PLATFORM | sha256sum --check

    tar -xzf eksctl_$PLATFORM.tar.gz -C /tmp && rm eksctl_$PLATFORM.tar.gz

    sudo install -m 0755 /tmp/eksctl /usr/local/bin && rm /tmp/eksctl

    elsctl version
    ```

* Install kubectl :

    ```
    curl -O https://s3.us-west-2.amazonaws.com/amazon-eks/1.36.2/2026-07-05/bin/linux/amd64/kubectl

    chmod +x ./kubectl

    mkdir -p $HOME/bin && cp ./kubectl $HOME/bin/kubectl && export PATH=$HOME/bin:$PATH

    kubectl version --client

    ```

* Install AWS CLI :

    ```
    curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
    unzip awscliv2.zip
    sudo ./aws/install
    aws --version

    aws configure 
    * it will ask you for access key and secret key . get it from AWS console
    ```
